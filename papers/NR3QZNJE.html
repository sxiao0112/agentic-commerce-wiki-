WebShop: Towards Scalable Real-World Web Interaction with Grounded Language Agents

Contribution

The authors develop WebShop, a large-scale simulated e-commerce environment for training and evaluating autonomous agents that interact with web pages using natural language instructions. The environment contains 1.18 million real-world products scraped from Amazon and 12,087 crowdsourced text instructions describing shopping tasks. Agents must navigate multiple page types (search, results, item detail), formulate search queries, select products, choose options, and complete purchases. The authors train multiple models using imitation learning and reinforcement learning, achieving a success rate of 29% with the best model (IL+RL), significantly above a rule baseline at 9.6% but well below human expert performance at 59%. They also demonstrate sim-to-real transfer, deploying agents trained on WebShop to operate directly on Amazon.com and eBay.com without fine-tuning.

Research Question

How can language understanding and sequential decision-making be improved for agents that must interact with realistic, large-scale web environments? The authors address the gap between static NLP benchmarks and truly interactive environments, specifically focusing on tasks that require compositional instruction understanding, query reformulation, robust semantic matching of noisy web text, and long-term strategic exploration across multiple pages.

Task

Given a natural language instruction specifying product requirements (including desired attributes, options, and price constraint), an agent navigates a simulated e-commerce website to find, customize, and purchase a matching product. Instructions are generated based on target products and specify a subset of product attributes, options, and an upper-bound price. The task requires the agent to reason about compositional requirements and match them against product metadata across multiple pages.

Data

The product corpus consists of 1,181,436 products scraped from Amazon.com across five categories (fashion, makeup, electronics, furniture, food) using 113 sub-category queries. Product texts have an average length of 262.9 tokens with a vocabulary of 224,041 words. Each product is annotated with a hidden set of attributes (670 unique attributes total, averaging 3.1 per product) extracted via TF-IDF scoring and manual filtering, and 842,849 unique options available across products (averaging 0.67 options per product). Natural language instructions (12,087 total, averaging 15.9 words) were collected via Amazon Mechanical Turk from workers given a target product and asked to write instructions without copying the full title. The authors collected 1,012 human demonstrations for task verification and imitation learning, and an additional 54 expert demonstrations for hyperparameter tuning. Human trajectories were collected for all 500 test instructions. The data is split into train/dev/test at 10,587 / 1,000 / 500 instructions.

Metrics

Task Score is computed as 100 times the average reward across episodes. Success Rate is the fraction of episodes where the agent achieves a perfect reward (r = 1.0). The reward function combines four components: attribute matching (intersection of instruction and product attributes), option matching (intersection of instruction and product options), price satisfaction (binary check that product price is within budget), and type reward (heuristic text matching to ensure the product is fundamentally the correct type). The formula is r = r_type · (|U_att ∩ Y_att| + |U_opt ∩ Y_opt| + 1[y_price ≤ u_price]) / (|U_att| + |U_opt| + 1), where r_type accounts for coarse-grain category match, fine-grain category match, and title overlap.

Baselines

A simple rule baseline searches the exact instruction text and chooses the first returned product without selecting any options, achieving a score of 45.6 and success rate of 9.6%. The authors also evaluate a Choice oracle with access to the ground-truth reward function and hidden attributes/options; when given human-quality search queries, this oracle achieves 85%+ success rate, demonstrating that search quality and option selection are key bottlenecks.

Method

The authors train agents using two approaches: imitation learning (IL) and reinforcement learning (RL). For IL, they separate search generation and action choice. Search is modeled as a sequence-to-sequence problem, fine-tuning a BART model on 1,421 instruction-search pairs from human demonstrations. Choice is modeled as ranking available actions; a BERT-based transformer encodes both the observation (page text, with product images encoded via ResNet-50) and each candidate action, with a cross-attention layer combining their representations before a learned linear scoring layer. During inference, the search model generates top-5 queries via beam search and one is chosen randomly for exploration. At other page types, an action is sampled from the learned policy. For RL, the authors initialize from the IL model and apply policy gradient with value baseline, freezing the search generator and letting the choice policy learn to explore the top-10 generated queries. This IL+RL approach prevents language drift during RL training.

Setup

The environment is implemented using Flask and OpenAI Gym with two rendering modes: HTML (for human interaction) and simple mode (stripped of metadata, for agents). A deterministic search engine using BM25 retrieval (via Pyserini) returns the top 50 results across five pages. The transition function is deterministic; state spaces consist of search, results, item, and item-detail pages. Human performance is measured in HTML mode; all model training and evaluation uses simple mode. Agents are evaluated on the i.i.d. test split (500 instructions) against human expert performance measured on the same set.

Results

The IL model achieves a score of 59.9 and success rate of 29.1%, significantly outperforming the rule baseline but lagging human experts at 82.1 / 59.6%. IL+RL improves the score to 62.4 but slightly reduces success rate to 28.7%, suggesting RL makes the agent greedier and less exploratory (average trajectory length drops from 9.4 to 4.8 steps). Ablations show that language pre-training (LP) is critical—removing pre-trained BERT weights degrades success rate by two-thirds. Fine-grained analysis reveals the largest performance gap between agents and humans is in option selection (28 percentage point gap). A Choice oracle experiment shows that with perfect action selection, success rate reaches 85%, confirming that choosing correct options is the primary bottleneck. For sim-to-real transfer on Amazon and eBay without fine-tuning, IL+RL achieves scores of 65.9 / 25% and 62.3 / 21% respectively, outperforming the rule baseline by large margins. Humans achieve slower but higher-quality performance (88.2 / 65% on Amazon and 79.7 / 40% on eBay, but taking an average of 815 seconds per episode compared to <8 seconds for agents).

Findings

Agents struggle with four key challenges: (1) generating effective search queries and reformulating them adaptively (agents learn to search but achieve only 38-45% option match compared to humans at 74%); (2) semantic matching of noisy web text, particularly for synonyms and paraphrases in option selection; (3) strategic exploration and long-term memory to compare products and backtrack (humans explore 11.3 items and 7+ states per trajectory vs. agents averaging 4-5 items and 4-5 states); and (4) balancing exploration vs. exploitation during RL (RL reduces exploration which helps with low-level scores but hurts option matching). Sim-to-real transfer results are promising, with agents maintaining similar performance on real e-commerce sites despite differences in search engines and product catalogs, validating the realism and transferability of the WebShop task. Human failure analysis identifies impatience as a common pattern—workers commit to the first reasonable match rather than exploring and refining searches.

Conclusion

WebShop provides a realistic, scalable benchmark for developing grounded language agents capable of complex sequential decision-making over large-scale web environments. The benchmark combines realistic linguistic and visual content from real products with automatically computable rewards, avoiding expensive human-in-the-loop evaluation. The significant gap between agent and human performance (29% vs. 59% success rate) indicates ample room for research advances. The authors identify promising directions including multi-modal pre-training on web data, query reformulation techniques, improved exploration and memory mechanisms, and better semantic understanding of noisy web content. The successful sim-to-real transfer to real shopping websites demonstrates the benchmark's practical value for developing autonomous web agents.

Related Work

Reinforcement learning on the web

End-to-End Goal-Driven Web Navigation — Nogueira and Cho — Prior work introduced WikiNav, a navigation-only benchmark restricted to following hyperlinks. World of Bits (WoB) and MiniWoB — Shi et al., Gur et al., Humphreys et al., others — RL agents trained to complete web tasks via pixel and DOM observations; variants explored curriculum learning, meta-learning, DOM tree representations, and behavioral cloning, but lacked long-range decision-making across multiple pages and did not scale beyond low-level mouse/keyboard actions. Workflow-Guided Exploration — Liu et al. — Applied exploration strategies to web navigation tasks. Adversarial Environment Generation for Learning to Navigate the Web — Gur et al. — Generated challenging web environments. AndroidEnv and MoTIF — Toyama et al., Burns et al. — Environments for training agents on mobile apps and services.

Non-interactive web-based tasks

Predicting web elements — Pasupat and others — Supervised classification on webpage structure. Generating API calls — Su et al. — Semantic parsing to generate API calls for web navigation. Mapping natural language commands to web elements — Pasupat et al. — Mapping instructions to web actions via supervised learning. The Klarna Product Page Dataset — Hotti et al. — Labeled product pages for supervised learning, but used single-decision classification rather than sequential interaction.

Leveraging the web for traditional NLP tasks

Information extraction — Narasimhan et al., others — Using web for evidence gathering. Question answering on the web — Various authors — Web search as a knowledge retriever for QA. Dialog and language models on webtext — Aghajanyan et al., Shuster et al., others — Pre-training and prompting with web content. WebGPT — Nakano et al. — Web interface with search engine for RL-based question answering, but required human-in-the-loop evaluation and had less diverse action/observation space.

Language grounding and agents

Survey of reinforcement learning informed by natural language — Luketina et al. — Overview of language-guided RL. Task-oriented dialogue as dataflow synthesis — Andreas et al. — Grounding language in task-oriented settings. MultiWOZ — Budzianowski et al. — Multi-domain task-oriented dialogue dataset. ALFRED — Shridhar et al. — Grounded instructions for embodied agents in simulated environments. Keep CALM and Explore and Reading and acting while blindfolded — Yao et al. (authors themselves) — Language understanding and exploration in text-based games. SILG: The multidomain symbolic interactive language grounding benchmark — Zhong et al. — Language grounding across domains. Interactive fiction game playing — Guo et al. — Multi-paragraph comprehension and RL in interactive narrative.

Query generation and reformulation

Internet-augmented dialogue generation — Komeili et al. — Query formulation in dialogue. Task-Oriented Query Reformulation with Reinforcement Learning — Nogueira and Cho — Query refinement via RL. Deep reinforced query reformulation for information retrieval — Wang et al. — Learned query reformulation. Bridging the gap between indexing and retrieval — Zhuang et al. — Query generation for retrieval. Boosting Search Engines with Interactive Agents — Adolphs et al. — Using agents to improve search.

Exploration, memory, and decision-making

Multi-stage episodic control for strategic exploration in text games — Tuyls et al. — Memory and exploration strategies for long-horizon tasks. Go-Explore — Ecoffet et al. — Hard-exploration approach for RL. Curiosity-driven exploration by self-supervised prediction — Pathak et al. — Intrinsic motivation for exploration. Towards mental time travel — Lampinen et al. — Episodic and working memory for RL agents. Generalization of reinforcement learners with working and episodic memory — Fortunato et al. — Memory mechanisms in RL. Multi-agent Communication meets Natural Language — Lazaridou et al. — Communication and language in multi-agent settings.
