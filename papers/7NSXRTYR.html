$τ^2$-Bench: Evaluating Conversational Agents in a Dual-Control Environment

Contribution

The authors introduce τ²-bench, a benchmark that extends prior conversational agent evaluation by introducing a dual-control environment where both the AI agent and a simulated user can call tools and modify a shared world state. Unlike existing benchmarks where the user is passive and provides information only, this work models the interaction as a Decentralized Partially Observable Markov Decision Process (Dec-POMDP) where both parties possess distinct tool affordances. The benchmark includes a novel telecom domain with a compositional task generator that programmatically creates diverse, verifiable tasks from atomic components. A key finding is that agent performance drops substantially (approximately 20% pass^1) when shifting from autonomous operation to dual-control scenarios requiring coordination and communication, isolating communication and coordination as critical bottlenecks separate from pure reasoning capability.

Research Question

How can conversational agent benchmarks be designed to capture real-world collaboration scenarios where users actively participate in modifying the environment, and how do such dual-control settings expose distinct failure modes in current language models beyond reasoning capability?

Task

The benchmark focuses on evaluating agents in multi-turn task-oriented interactions where success requires coordination between an LLM-based agent and an LLM-based simulated user. The primary domain is telecom customer support, where users experience issues and agents must diagnose and guide them to perform resolution actions. The task involves both parties calling tools over a shared, observable environment state to reach a resolved state.

Data

The telecom domain comprises 2285 automatically generated tasks, with 114 tasks selected to form a balanced dataset across different intents and complexity levels. Tasks span three primary user intents: service_issue (simple one-to-eight action resolution paths), mobile_data_issue (typically four-to-eight action paths with prerequisite diagnostics), and mms_issue (complex six-to-twelve action paths requiring conditional reasoning). The benchmark also includes retail and airline domains from the prior τ-bench work (115 and 50 tasks respectively). Each task can be assigned to a user persona (None, Easy, or Hard) representing different levels of technical familiarity. The agent and user each interact with separate databases: the agent accesses customer relationship management data, while the user interfaces with a mocked phone device with status attributes like airplane mode and data connectivity.

Metrics

Performance is evaluated using pass^k metrics, measuring the fraction of k independent runs that achieve task success. Tasks are verified using multiple evaluation criteria including database state assertions, status assertions that check conditions in the final world state via predefined assertion functions, natural language assertions over conversation history, action matching that verifies solution functions exist in the trajectory, and communication information checks. The analysis includes fine-grained diagnosis through ablation studies: a no-user autonomous mode isolates reasoning capability, the oracle-plan mode provides ground-truth action sequences to focus on communication, and the default dual-control mode tests full coordination.

Baselines

Four large language models are evaluated: gpt-4.1, o4-mini, gpt-4.1-mini, and claude-3.7-sonnet. The user simulator is implemented using gpt-4.1. Results show substantial performance variation: gpt-4.1 achieves 34% pass^1 on telecom compared to 74% on retail and 56% on airline; claude-3.7-sonnet achieves 49% on telecom; o4-mini and gpt-4.1-mini perform around 42-50% on telecom. The no-user autonomous mode shows significantly higher performance (52-68% for the evaluated models), while oracle-plan with ground-truth sequences reaches 73-96%, demonstrating that communication and coordination are major challenges. Performance degrades substantially as the number of required actions increases, with near-zero pass rates for sequences exceeding seven actions. Issue type analysis reveals that service_issue tasks are substantially easier than mobile_data_issue and mms_issue tasks. User persona effects show agents perform notably better on easy-persona tasks compared to hard-persona or no-persona baselines.

Conclusion

τ²-bench provides a controlled testbed for evaluating agents that must both reason effectively and guide user actions in collaborative environments. The dual-control formalism using Dec-POMDP enables realistic simulation of scenarios where users possess agency and affordances. The compositional task generator ensures systematic domain coverage and verifiable correctness. User simulation reliability is substantially improved compared to prior benchmarks: the telecom domain shows only 16% total user simulator error rate with 6% critical errors, compared to 40-47% error rates in retail and airline domains. The key finding—that coordination and communication overhead introduces a ~20% performance penalty even for models that can reason autonomously—demonstrates that current LLMs struggle significantly with collaborative problem-solving despite adequate reasoning capability. The work identifies agent coordination and communication as critical bottlenecks for real-world deployment in customer support and similar domains.

Related Work

Task-Oriented Dialogue and Agent Benchmarks

τ-bench — Yao et al. — Measures reliability of language agents in multi-turn task-oriented conversations across retail and airline domains while respecting domain policies and introduces pass^k metrics for evaluating run consistency.

FlowBench — Xiao et al. — Isolates planning in tool-using agents by injecting explicit workflow knowledge via natural language, pseudocode, or flowchart specifications to test workflow-guided planning.

IntellAgent — Levi & Kadar — Provides an evaluation pipeline to programmatically build synthetic test suites from structured policy graphs, achieving high correlation with τ-bench as a fast synthetic proxy task.

APIGen-MT — Prabhakar et al. — Explores fine-tuning tool-calling agents by generating conversation blueprints and simulating conversational traces based on explicit tool-call dependencies.

ToolSandbox — Lu et al. — Focuses on creating stateful tools to enable more fine-grained evaluation of agent progress over time.

AgentBench — Liu et al. — Evaluates LLMs as agents across diverse benchmarking scenarios beyond conversation.

WebShop — Yao et al. — Tests grounded language agents in scalable real-world web interaction settings.

WebArena — Zhou et al. — Provides a realistic web environment for building autonomous agents.

Language Agents and Tool Use — Yao et al.; Qin et al.; Huang et al. — Foundational work on agent reasoning and LLM tool-calling capabilities.

User Simulation for Conversational Systems

User Simulation in Task-Oriented Dialogue — Pietquin & Hastie — Comprehensive survey of metrics for evaluating user simulations in dialogue systems.

LLMs as User-Agents — Kazi et al. — Demonstrates effective use of LLMs as user simulators in task-oriented dialogue evaluation when combined with careful prompting and state tracking.

Multi-Agent Systems

MultiAgentBench — Zhu et al. — Evaluates collaboration and competition of LLM agents in multi-agent settings, complementing the focus on asymmetric agent-user collaboration.

Foundational Frameworks

Decentralized POMDPs — Oliehoek & Amato — Provides the formal framework underlying the dual-control environment modeling in τ²-bench.
