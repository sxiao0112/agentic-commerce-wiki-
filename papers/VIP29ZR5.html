VisualWebArena: Evaluating Multimodal Agents on Realistic Visual Web Tasks

Contribution

VisualWebArena is a benchmark suite of 910 realistic, visually grounded tasks for evaluating multimodal agents on web environments. The benchmark comprises three diverse and complex web-based environments: Classifieds (a new contribution with real-world data scraped from Craigslist), Shopping (adapted from prior work), and Reddit (adapted from prior work). All tasks require visual understanding to effectively solve, addressing a significant gap in prior benchmarks that primarily focused on text-based agents. The authors also introduce a novel observation representation inspired by Set-of-Marks prompting, where interactable webpage elements are automatically annotated with bounding boxes and unique IDs, and demonstrate that this representation improves performance of vision-language models on visually complex sites.

Research Question

How should multimodal agents be evaluated on realistic web tasks that inherently require both visual and textual understanding? What are the gaps in the capabilities of state-of-the-art vision-language models when applied to visually grounded web navigation, and how can improved representations simplify agent action spaces and improve performance?

Task

VisualWebArena comprises 910 diverse and realistic tasks distributed across three environments: Classifieds (232 tasks, 25.5%), Shopping (464 tasks, 50.9%), and Reddit (171 tasks, 18.7%), with 45 additional multi-site tasks (4.9%). Each task is human-written with explicit intent templates that were manually expanded to create variations, encouraging annotators to be creative with visual layouts, input images, and cross-site functionalities. Tasks are classified by action difficulty (easy: three or fewer actions; medium: four to nine actions; hard: ten or more) and visual difficulty (easy: basic color and shape identification; medium: pattern and semantic understanding with OCR on longer text; hard: multiple images, small text OCR, or fine details). Tasks range from information-seeking (requiring text output) to navigation and actions that modify environment state. Five percent of tasks (46) are intentionally unachievable to test agent failure detection.

Data

The Classifieds environment contains 65,955 real-world listings scraped from Craigslist over three weeks, covering the Northeastern United States region. Personally identifiable information was redacted using the scrubadub Python package. The Shopping environment reuses product information from prior work, sourced from Amazon and released in WebShop. The Reddit environment contains 31,464 posts with diverse images across different subreddits. The Wikipedia knowledge base is referenced by several tasks. All observations include webpage URLs, open tabs (with multi-tab support), and the focused tab's content represented in four ways: raw HTML DOM trees, accessibility trees, web screenshots as RGB arrays, and a novel Set-of-Marks representation that automatically labels every interactable element with a bounding box and unique ID. For 25.2% of tasks, the intent includes one or more input images sourced from royalty-free attribution-free sources or MS-COCO.

Metrics

The benchmark introduces a functional evaluation paradigm with execution-based reward primitives that assess correctness on open-ended tasks. For information-seeking tasks, evaluation functions include exact_match (output must equal ground truth exactly), must_include (output must contain all expected elements), fuzzy_match (GPT-4-Turbo semantic evaluation of output against ground truth), and must_exclude (output must not contain prohibited elements). Visual functions for open-ended tasks include eval_vqa (Vision-Language Model visual question answering with BLIP-2-T5XL), and eval_fuzzy_image_match (structural similarity index measure against a ground-truth image with a configurable threshold). For navigation and action tasks, evaluation uses a locator to identify target objects on the final webpage state and applies the above information-seeking functions to check correctness.

Baselines

The authors evaluate multiple baseline agents: text-only LLM agents (LLaMA-2-70B, Mixtral-8x7B, Gemini-Pro, GPT-3.5-Turbo, GPT-4-Turbo) provided with accessibility tree representations and three in-context examples; caption-augmented LLM agents combining text-only models with image captions from BLIP-2-T5XL or LLaVA-7B; and multimodal vision-language models (IDEFICS-80B-Instruct, CogVLM, Gemini-Pro, GPT-4V) with two observation settings: image screenshot plus captions plus accessibility tree, and image screenshot plus captions plus Set-of-Marks annotations. All models use prompt-based, in-context learning approaches. Human performance is measured on 230 representative tasks (one per template) with seven college students as raters. The evaluation also includes analysis of recently released models (GPT-4o, Gemini-Pro-1.5, Gemini-Flash-1.5, Llama-3-70B-Instruct) reported after the main submission deadline.

Results

Text-only LLM agents achieve poor success rates, with the best model (GPT-4-Turbo) at 7.25% overall; caption augmentation significantly improves GPT-4 from 7.25% to 12.75%. Multimodal agents substantially outperform text-only approaches: GPT-4V achieves 15.05% overall success rate, with Gemini-Pro at 6.04%. The Set-of-Marks representation further improves GPT-4V's success rate to 16.37% overall, with particularly large gains on visually dense sites (Classifieds 12.38%→17.14%, Reddit 8.12%→9.83%), though improvements for other multimodal models are negligible. Human raters achieve 88.7% success rate overall (91.07% on Classifieds, 87.10% on Reddit, 88.39% on Shopping), indicating significant headroom. Analysis of task subsets reveals that agents perform worse on tasks requiring OCR (13.4% vs 16.9% for GPT-4V+SoM), perform better on exact image matching (18.9% vs 16.2%), and perform better on tasks with image inputs (19.0% vs 14.9%). Common failure modes include errors over longer horizons where agents undo correct actions, poor performance on seemingly easy tasks, giving up too early without exploring alternatives, getting stuck in loops oscillating between pages, making unnecessary actions, appending text instead of replacing it, and repeating actions when text fields contain unwanted content. Recently released models show improved performance: GPT-4o achieves 19.78% success, while Llama-3-70B-Instruct (caption-augmented) reaches 9.78%.

Related Work

Language-Guided Web Agent Benchmarks

Earlier works introduced reinforcement learning environments and extended them into web domains. Recent efforts have developed benchmarks with tasks on static internet pages and simulated web environments. AgentBench evaluates agents across database management and operating system functionalities beyond the web. VisualWebArena extends this trajectory with a focus on visual grounding, distinct from WebArena which primarily uses accessibility trees and does not emphasize visual understanding.

LLM Agents

State-of-the-art Transformer-based LLMs have demonstrated impressive few-shot learning, reasoning, instruction following, and long-context capabilities. Recent work leverages these abilities for web agents through recursive prompting to improve GPT-4 performance on MiniWoB++, orchestrating multiple LLM agents to improve performance on WebShop, and fine-tuning LLaMA-2 on interaction trajectories with instructions. VisualWebArena benchmarks such agents but focuses on the necessity of multimodal processing for tasks where visual information is critical.

Vision-Language Models

Vision-language models have been developed through frozen visual encoders mapping to LLM embedding spaces, cross-attention mechanisms at larger scales, trainable visual expert modules, and instruction-tuning on image-instruction pairs. Models such as GPT-4V and Gemini enable multimodal processing with interleaved visual and textual inputs. Recent work explores VLMs for mobile-platform and web-based agents. Contemporaneous work on action grounding identifies appropriate HTML elements for agent execution, while VisualWebArena's Set-of-Marks approach uses JavaScript to produce marked-up page representations that agents can directly reference.

Conclusion

VisualWebArena addresses a critical gap in agent benchmarking by introducing a large-scale suite of visually grounded web tasks where visual understanding is inherently necessary rather than supplementary. The benchmark demonstrates that strong vision-language models substantially outperform text-only LLMs but remain far below human performance, indicating significant room for improvement in agent visual understanding, reasoning, and planning. The Set-of-Marks representation shows promise for simplifying action spaces on visually complex sites, particularly for the strongest VLMs. The benchmark and analysis of failure modes provide a foundation for advancing multimodal web agents toward more capable, reliable autonomous behavior on realistic web interfaces. Future work should address reasoning and planning abilities, improve handling of longer horizons and multi-step tasks, enhance OCR capabilities, and develop more sophisticated tracking of past states and execution history.
