ShopGym: An Integrated Framework for Realistic Simulation and Scalable Benchmarking of E-Commerce Web Agents

Contribution

ShopGym is an integrated framework comprising two complementary components: ShopArena, which converts live storefronts into self-contained, anonymized sandbox shops through specification synthesis and staged code generation; and ShopGuru, which synthesizes grounded benchmark tasks that are valid against the generated shops. The framework addresses a core methodological gap in e-commerce agent evaluation: existing approaches force a tradeoff between live-website realism (which is non-stationary and irreproducible) and sandbox control (which lacks diversity). ShopGym produces evaluation artifacts that are simultaneously realistic, diverse, controllable, inspectable, and reproducible.

Research Question

How can the field systematically construct evaluation environments for e-commerce web agents that preserve meaningful task structure and agent-evaluation signals from live storefronts while enabling controllable, reproducible, and scalable scientific comparison?

Conclusion

ShopGym addresses a central methodological gap by combining realistic simulation with controlled benchmarking. Generated shops are structurally comparable to real storefronts and preserve meaningful behavioral signal for agent evaluation. Agent performance on synthetic twins positively tracks performance on live storefronts, while fully synthetic composite shops yield benchmarks of comparable difficulty. The framework provides a practical middle ground between live-web realism and sandbox control, offering a scalable foundation for more reproducible and interpretable evaluation of e-commerce web agents.

Task

ShopGym produces grounded benchmark tasks organized around seven skill categories: Product Discovery (exact search, substitute search), Filter-Selection (collection browse, collection filter), Information-Seeking (shipping policy lookup, returns policy lookup), and E2E shopping journeys. Short-horizon tasks are generated deterministically and evaluate primitive capabilities. Long-horizon journeys are LLM-authored using few-shot prompts grounded in human-shopper behavior patterns, including multi-step intents that combine navigation, filtering, information seeking, and cart actions. A post-generation validation pipeline ensures all generated tasks are feasible against the shop's actual catalog, collections, and page structure.

Data

ShopArena generates synthetic sandbox shops from live seed storefronts through an exploration-specification-generation pipeline. The exploration phase browses seed storefronts and writes anonymized specifications capturing navigation structure, affordances, page organization, and catalog statistics. Specifications are composed from multiple seeds when provided, enabling a single sandbox shop to span structural and behavioral diversity that no individual source storefront would cover. The framework generated six shops for validation: three constructed with synthetic product data and three with real product data (twins). Synthetic product names, descriptions, and imagery are generated rather than copied, maintaining anonymity while preserving structural alignment with source storefronts. The validation corpus includes 224 generated tasks across the six shops.

Metrics

Structural validity is evaluated using three axes: observation and interaction complexity (measured by accessibility-tree depth and counts of interactive elements), state-transition complexity (using directed graph metrics of distinct UI states and transitions), and behavioral consistency (comparing agent success rates across models and harnesses on real vs. synthetic twin shops). Agent evaluation uses LLM-as-judge scoring of task completion across three frontier models (GPT-5-mini, Gemini 3 Flash, GPT-5) in two harnesses (BrowserGym with accessibility trees; internal harness with screenshots and accessibility trees). Behavioral validation shows that agent performance on synthetic twins positively correlates with performance on live storefronts.

Baselines

The paper evaluates three frontier LLM models as agent baselines: GPT-5-mini, Gemini 3 Flash, and GPT-5. On short-horizon tasks in the internal harness, success rates range from 70-77% (GPT-5-mini to GPT-5). On long-horizon tasks, success rates range from 54-57% (GPT-5-mini to GPT-5), indicating that the benchmark generates meaningfully hard tasks. The BrowserGym harness shows similar patterns, with short-horizon success rates around 76-86% and long-horizon rates around 48-62%.

Related Work

Static web environments and benchmarks

Mind2Web — Online dataset providing large-scale offline traces from real websites, emphasizing breadth and cross-site generalization. OPeRA — Dataset of human shopping observations, personas, rationales, and actions from real Amazon sessions. WebArena — Self-hosted, fully functional websites with executable tasks and reproducible evaluation. VisualWebArena — Extension of WebArena to visually grounded tasks. WebShop — Synthetic storefront with 1.25M products and grounded language agent interactions. ShoppingBench — Large shopping sandbox with API-based interaction, focused on intent grounding. ShopSimulator — Chinese web environment for multi-turn shopping dialog and fine-grained product differentiation. WebMall — Four simulated shops with authentic product offers and comparison-shopping tasks. These existing benchmarks enable controlled evaluation but are tied to fixed sets of layouts, taxonomies, and policies, capturing only a limited slice of real-world e-commerce diversity.

Live-website evaluation

Online-Mind2Web — Agent evaluation directly on live websites with real shopping domains. WebVoyager — End-to-end web agent evaluated on live shopping sites. DeepShop — Shopping assistant benchmark evaluated directly on live websites. These approaches improve diversity and realism but depend on external sites whose layouts, inventories, and policies may change without notice, making reproducibility difficult.

Automated environment and task generation

Gym-Anything — Multi-agent pipeline treating environment setup as installation and configuration, producing 10K+ tasks. WebArena-Infinity — Generates synthetic web apps from user manuals. WebForge — Plan/Generate/Refine/Validate pipeline for creating self-contained web environments at scale. VeriEnv — Constructs executable synthetic versions of real websites with deterministic rewards. Go-Browse — Multi-agent pipeline for generating tasks and trajectories via website navigation while maintaining a visited URL graph. These approaches sacrifice fidelity by deriving environments from manuals or ungrounded LLM design choices. ShopArena grounds generation in observed real shops through an exploration phase that produces an anonymized shop manual, then synthesizes calibrated sandbox shops from that manual while preserving diversity and determinism.

LLM-based agentic systems and agent evaluation

Shopping companion — Memory-augmented LLM agent for real-world e-commerce tasks. Customer-r1 — Personalized simulation of human behaviors via RL-based LLM agent. See, think, act — Online shopper behavior simulation with vision-language model agents. LLASA — Large language and e-commerce shopping assistant. ProductResearch — Training e-commerce deep research agents via multi-agent synthetic trajectory distillation. Simgym — Traffic-grounded browser agents for offline A/B testing. AgentA/B — Automated and scalable web A/B testing with interactive LLM agents. These works address agent training, simulation, and evaluation in e-commerce, complementing ShopGym's focus on environment construction and controlled benchmarking.
