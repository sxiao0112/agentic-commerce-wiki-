WebArena: A Realistic Web Environment for Building Autonomous Agents

Contribution

The paper introduces WebArena, a fully functional, self-hosted web environment designed to evaluate autonomous agents on realistic web-based tasks. The environment consists of four operational websites spanning e-commerce, social forums, collaborative software development, and content management systems, enhanced with utility tools and knowledge resources. Accompanying the environment is a benchmark of 812 annotated long-horizon tasks with evaluation metrics based on functional correctness rather than action-sequence matching.

Research Question

How can autonomous agents be fairly and comprehensively evaluated on complex, realistic web tasks when current environments often oversimplify real-world scenarios, lack dynamic interaction, or evaluate only textual surface-form accuracy rather than whether tasks are actually completed?

Task

The benchmark covers three task categories: information-seeking tasks requiring textual answers derived from user-centric content across multiple pages; site-navigation tasks requiring agents to locate specific information or sections using various interactive elements; and content-and-configuration tasks requiring agents to create, revise, or configure content and settings in the web environment. Tasks are instantiated from 241 templates, with each template producing multiple variations to enable evaluation of consistency across similar-but-distinct task instances.

Data

WebArena comprises four fully functional websites built from open-source libraries with data imported from real-world counterparts. The e-commerce site (OneStopShop) built on Adobe Magento contains 90k products with prices, options, descriptions, images, and reviews across 300 categories. The social forum platform (Reddit-like) deployed on Postmill software contains 95 subreddits, 127k posts, and 661k users. The collaborative development platform is GitLab with 300 repositories sampled to represent a realistic distribution from popular to personal projects. The content management system is built from Adobe Magento's admin portal. Additional resources include offline Wikipedia (knowledge cutoff May 2023), tool websites for maps (OpenStreetMap confined to northeast US), calculator, and scratchpad. User profiles simulate realistic access patterns across platforms with diverse roles and permission levels.

Metrics

For information-seeking tasks, three evaluation functions compare predicted answers to reference answers: exact_match for standardized-format responses; must_include for verifying presence of required key concepts; and fuzzy_match using GPT-4 to assess semantic equivalence across diverse phrasings. For site-navigation and content-and-configuration tasks, programmtic reward functions examine intermediate execution states (databases, webpage content, URLs) to verify that outcomes align with intended results. Tasks marked as unachievable (due to missing information or insufficient permissions) are evaluated by whether agents appropriately refuse completion rather than hallucinating answers.

Baselines

The paper evaluates three LLMs (GPT-4, GPT-3.5, and TEXT-BISON-001) using two prompting strategies: direct action prediction given current observation and intent, and chain-of-thought reasoning before action. A detailed system prompt specifies all available actions, rules for valid execution, and instructions for handling unachievable tasks. Two few-shot examples demonstrate the expected behavior. Agents use accessibility trees with element IDs as observations, enabling agents to select elements by ID rather than coordinates. Human performance is measured by five computer-science graduate students completing one task per template from 170 templates.

Results

GPT-4 with chain-of-thought prompting achieves an end-to-end task success rate of 11.70%, significantly below human performance of 78.24%. Removing an explicit instruction asking models to recognize unachievable tasks increases GPT-4 success to 14.41% on achievable tasks (while reducing detection of genuinely unachievable tasks to 44.44%). GPT-3.5 achieves only 8.75% with chain-of-thought and 6.41% without. TEXT-BISON-001 achieves 5.05%. Analysis reveals two primary failure modes: models prematurely conclude tasks are impossible due to instruction framing, and models demonstrate inconsistent performance across task variations from the same template (GPT-4 achieves 100% on only 4 of 61 templates where it succeeds on at least one variant). Common error patterns include observation bias (latching onto first relevant information without verification), failures in observation interpretation (overlooking granular details like previously entered input), hallucination of incorrect answers, and repetition of invalid actions.

Related Work

Benchmarks for Controlling Agents through Natural Language

Vision-and-language navigation: Anderson et al. 2018 — Interpreting visually-grounded navigation instructions in real environments; establishes foundational methodology for grounding language to embodied action.

Form/QAWoB: Shi et al. 2017 — Platform for web-based agents with static states; early work demonstrating limitations of non-dynamic environments for fair evaluation.

Reinforcement learning on web interfaces: Liu et al. 2018 (ICLR 2018) — Workflow-guided exploration on web interfaces; introduces structured navigation but remains simplified relative to real-world web.

Mind2Web: Deng et al. 2023 — Generalist agent for the web with realistic environments; demonstrates value of diverse human tasks but relies on static cached states.

VirtualHome: Puig et al. 2018 — Simulating household activities via programs; extends from physical to domestic environments but maintains simulation-specific task vocabulary.

ALFRED: Shridhar et al. 2020 (CVPR 2020) — Benchmark for interpreting grounded instructions for everyday tasks; pioneering work on long-horizon instruction following but in visual rather than web environments.

ALFWorld: Shridhar et al. 2021 (ICLR 2021) — Aligning text and embodied environments for interactive learning; unifies embodied and text-based agents.

MiniWoB++: Liu et al. 2018 — Suite of web-based task variants; introduces dynamic interaction but with simplified websites and task composition.

Webshop: Yao et al. 2022a — Scalable real-world web interaction with grounded language agents; demonstrates task complexity growth but in constrained domain.

AndroidEnv: Toyama et al. 2021 — Reinforcement learning platform for Android; achieves realistic environment through live applications but sacrifices reproducibility.

Interactive Decision-Making Agents

WebGPT: Nakano et al. 2021 — Search the web and read results to answer questions; early demonstration of language models on web tasks.

Web agent via JavaScript synthesis: Gur et al. 2023 — Real-world web agent with planning, long context understanding, and program synthesis; shows alternative control modality through code generation.

Pixel-to-actions: Lee et al. 2023, Shaw et al. 2023 — Predict actions based on web screenshots rather than DOM text; explore multimodal observation representation.

Hierarchical planning and state tracking: Huang et al. 2022 — Language models as zero-shot planners; demonstrates decomposition of long-horizon tasks.

Task composition as subgoals: Madaan et al. 2022, Zhou et al. 2022b — Break tasks into manageable sub-tasks; addresses complexity management.

Program-aided execution: Liang et al. 2023, Wang et al. 2023, Gao et al. 2023 — Program-aided language models and code-as-policies; aid sub-task management and skill reuse.

Search and backtracking: Yao et al. 2023, Long 2023 — Tree-of-thought and structured decision reconsideration; introduce planning rather than greedy step-by-step execution.

Failure recovery and self-correction: Shinn et al. 2023 (Reflexion), Kim et al. 2023 — Autonomous agents with dynamic memory and self-reflection; improve robustness through learned error handling.

Observation summarization: Sridhar et al. 2023 — Hierarchical prompting assists large language model on web navigation; compress observation space for context-limited models.
