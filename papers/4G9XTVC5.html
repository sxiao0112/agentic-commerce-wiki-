AgentDyn: Are Your Agent Security Defenses Deployable in Real-World Dynamic Environments?

Contribution

The authors introduce AgentDyn, a manually designed benchmark for evaluating whether prompt injection defenses on autonomous LLM agents remain deployable under practical dimensions that existing benchmarks overlook. The benchmark comprises three application-domain scenarios (Shopping, GitHub, Daily Life) with 60 open-ended user tasks and 560 injection test cases, featuring dynamic planning requirements, helpful third-party instructions integrated throughout execution, and longer, multi-application workflows.

Research Question

Current agent security benchmarks like AgentDojo achieve near-perfect defense performance, yet a critical gap remains between benchmark evaluations and real-world deployment. The authors ask whether existing defenses are truly deployable when agents face dynamic open-ended tasks that require runtime adaptation, encounter benign and helpful instructions alongside malicious injections, and operate over extended action sequences across multiple integrated applications.

Task

AgentDyn comprises three task suites spanning seven application scenarios (Shopping, GitHub, Email, Bank, Web, FileSystem, Calendar): Shopping focuses on purchasing workflows; GitHub addresses repository management tasks; Daily Life covers routine activities including email management and bill payment. Each suite contains 20-39 tools and requires agents to execute tasks with an average trajectory length of 6.25-9.30 steps across 2.55-3.90 distinct application scenarios per task.

Data

AgentDyn includes 60 user tasks and 28 injection tasks that are combined in cross-product fashion to create 560 security test cases. Each user task enforces three design criteria: dynamic planning (agents must adapt strategies based on environmental feedback during execution), helpful instructions (at least one benign, necessary instruction embedded in the critical execution path), and task complexity (longer trajectories, larger tool sets, multi-application interactions). Test case design assumes practical threat models with injection vectors placed in realistic attack surfaces (e.g., advertisement banners on webpages) rather than unrealistic direct webpage manipulation; injection instructions are generalizable rather than user-specific.

Metrics

Three metrics evaluate both security and utility: Benign Utility measures baseline task completion without attacks. Utility under Attack evaluates task success when attacks are present. Attack Success Rate (ASR) measures the fraction of cases where the attacker's malicious goals succeed. The overall performance reported is the average across all three suites.

Baselines

The authors evaluate ten state-of-the-art defenses across four categories spanning twelve LLM agents (including commercial models Gemini, Claude, GPT families and open-source Llama, Qwen, Kimi). Prompting-based defenses include Prompt Sandwiching and Spotlighting. Filtering-based approaches include ProtectAI, PIGuard, and PromptGuard2. Alignment-based defenses are represented by Meta SecAlign-70B. System-level defenses include Tool Filter, CaMeL, Progent, and DRIFT. The evaluation on AgentDyn reveals that almost all existing defenses either lack sufficient security or suffer from severe overdefense, with filtering-based approaches struggling to distinguish helpful instructions from malicious injections, planning-dependent methods incurring sharp utility drops in dynamic scenarios, and the most successful alignment-based approach (Meta SecAlign) still achieving only 53.4% utility on AgentDyn compared to 80% on AgentDojo.

Conclusion

The authors conclude that nearly all existing defenses that achieve near-perfect performance on current agent security benchmarks struggle substantially on AgentDyn, revealing previously hidden failure modes. These findings underscore a fundamental mismatch between current benchmark evaluations and real-world deployment requirements, highlighting the urgent need for more realistic evaluation frameworks that incorporate dynamic planning, helpful environmental instructions, and complex multi-step tasks across integrated application environments.

Related Work

Prompt Injection and Agent Security

Ignore Previous Prompt: Attack techniques for language models — Perez & Ribeiro — seminal work introducing the concept of prompt injection attacks showing LLMs can be misled by crafted inputs leading to goal hijacking and prompt leakage.

Not What You've Signed Up For: Compromising Real-World LLM-Integrated Applications with Indirect Prompt Injection — Abdelnabi et al. — reveals indirect prompt injection attacks where malicious instructions embedded in third-party content hijack agent behaviors in real-world deployments.

OWASP LLM01 — OWASP — documents prompt injection as a top-tier AI security threat in deployed systems.

The Attacker Moves Second: Stronger Adaptive Attacks Bypass Defenses Against LLM Jailbreaks and Prompt Injections — Nasr et al. — demonstrates adaptive attacks that circumvent current defense approaches, underscoring the need for more robust evaluation frameworks.

Prompting-Based Defenses

The Sandwich Defense: Strengthening AI Prompt Security — Schulhoff — proposes repeating trusted user instructions after each tool invocation to maintain focus on original user intent.

Defending Against Indirect Prompt Injection Attacks with Spotlighting — Hines et al. — introduces special delimiters to mark untrusted tool outputs and force model attention to injection-prone segments.

Filtering-Based Defenses

Fine-Tuned DeBERTa-v3-Base for Prompt Injection Detection — ProtectAI — develops a classification model for detecting injection attempts in external data.

Llama Prompt Guard 2 — Meta — introduces a defensive classifier trained to identify injection instructions.

PIGuard: Prompt Injection Guardrail via Mitigating Overdefense for Free — Li et al. — proposes an approach to balance security and utility in filtering-based defenses.

Alignment-Based Defenses

StruQ: Defending Against Prompt Injection with Structured Queries — Chen et al. — splits context input into structured user query and external data, then fine-tunes the model to respond only to the user query.

SecAlign: Defending Against Prompt Injection with Preference Optimization — Chen et al. — applies preference optimization to encourage LLMs to follow user queries over external instructions.

Meta SecAlign: A Secure Foundation LLM Against Prompt Injection Attacks — Chen et al. — presents a defensive model fine-tuned on Llama-3.3-70B-Instruct achieving better balance between security and utility.

Llama Guard: LLM-Based Input-Output Safeguard for Human-AI Conversations — Inan et al. — develops an LLM-based safeguard for identifying unsafe content.

PromptArmor: Simple Yet Effective Prompt Injection Defenses — Shi et al. — proposes instruction identification and removal workflows leveraging LLMs as judges.

System-Level Defenses

IsolateGPT: An Execution Isolation Architecture for LLM-Based Agentic Systems — Wu et al. — introduces isolated execution environments for each application to minimize cross-application data flow risks.

Tool Filter (from AgentDojo) — Debenedetti et al. — identifies and isolates tools relevant to the user task, preventing irrelevant tools triggered by attacks from being executed.

CaMeL: Defeating Prompt Injections by Design — Debenedetti et al. — translates user tasks into static program code with strict information-flow controls for execution.

Progent: Programmable Privilege Control for LLM Agents — Shi et al. — leverages policy-updating mechanisms to dynamically control agent tool access during execution.

DRIFT: Dynamic Rule-Based Defense with Injection Isolation for Securing LLM Agents — Li et al. — combines initial planning to generate security constraints with dynamic validation to maintain functionality.

Existing Agent Security Benchmarks

InjecAgent: Benchmarking Indirect Prompt Injections in Tool-Integrated Large Language Model Agents — Zhan et al. — proposes a benchmark focusing on isolated steps but lacking end-to-end environmental interaction.

Agent Security Bench (ASB): Formalizing and Benchmarking Attacks and Defenses in LLM-Based Agents — Zhang et al. — develops an early evaluation framework also limited to isolated steps.

AgentDojo: A Dynamic Environment to Evaluate Prompt Injection Attacks and Defenses for LLM Agents — Debenedetti et al. — the most advanced existing benchmark providing simulated environments for multi-step interactions, but still featuring primarily static tasks, lacking helpful instructions, and employing oversimplified user task designs.

Real-World Agent Environments and Applications

On Generative Agents in Recommendation — Zhang et al. — explores autonomous agents in real-world recommendation applications.

Introducing ChatGPT Atlas — OpenAI — demonstrates agent deployment in real-world economic applications.

SOTOPIA: Interactive Evaluation for Social Intelligence in Language Agents — Zhou et al. — proposes interactive evaluation methods for agent behavior in social contexts.

Hello Again! LLM-Powered Personalized Agent for Long-Term Dialogue — Li et al. — examines long-horizon agent interaction scenarios.

WebArena: A Realistic Web Environment for Building Autonomous Agents — Zhou et al. — introduces a realistic web environment with dynamic interactive entities for agent evaluation.
