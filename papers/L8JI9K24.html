Sari Sandbox: A Virtual Retail Store Environment for Embodied AI Agents

Contribution

The authors introduce Sari Sandbox, a high-fidelity photorealistic 3D virtual retail store environment designed specifically for embodied agents performing grocery shopping tasks. They provide 250 interactive grocery items across three store layouts with a Python API for agent control. The authors also release SariBench, a benchmark dataset comprising 100 videos of human participants completing shopping tasks via VR, with varying difficulty levels (easy, average, difficult). Finally, they demonstrate a baseline embodied agent architecture using a vision language model and provide performance comparisons between human and agent completion times and success rates on easy tasks.

Research Question

How can embodied agents be trained and evaluated on retail-specific tasks in a photorealistic simulation environment? The authors specifically ask: what gap exists between human and AI agent performance on grocery shopping activities, and what baseline capabilities are needed for embodied agents to navigate, inspect, and manipulate retail items?

Task

The environment supports three difficulty-tiered shopping tasks: easy tasks require perception, navigation, and manipulation to find and retrieve a single item (e.g., find and pick up a box of cereal); average tasks add memory and task execution demands by requiring item retrieval and checkout (e.g., pick up a bottle of soda and scan at checkout); difficult tasks introduce decision-making and comprehension, requiring agents to compare products and make conditional actions (e.g., determine which of two products has lower sugar content, then scan the answer).

Data

SariBench comprises 100 videos collected from 20 human participants interacting with the Sari Sandbox environment via VR. Each participant completed seven assigned tasks: three easy, two average, and two difficult tasks. Environmental data was captured at 10 Hz including head position and rotation, hand position and rotation, grip state, and hovered or held items. Participants' think-aloud protocols were transcribed to capture reasoning. The Sari Sandbox itself contains 250 photorealistic 3D product models across 11 food categories (water, soda, juice, dairy, biscuits, cans, chips, nuts, soup, noodles, liquor), with annotations including category, name, price, net weight, ingredients, nutritional facts, allergens, and manufacturing origin.

Metrics

Human performance is measured by completion time (seconds) and completion rate (percentage of tasks successfully completed). Embodied agent performance is similarly evaluated using average time to completion and completion rate, with a success threshold of 45 minutes and failure defined as exceeding this limit or entering mode collapse (getting lost). Texture fidelity is assessed using PaddleOCR, measuring precision (0.986), recall (0.943), and character error rate (0.014) on product label text. Environment performance is measured in frames-per-second: Layout 1 achieved 26.73 FPS, Layout 2 achieved 23.23 FPS, and Layout 3 achieved 35.14 FPS.

Baselines

Human baselines across three store layouts show completion times of 47-73 seconds for easy tasks (88.88% to 100% success), 84-158 seconds for average tasks (87.50% to 100% success), and 76-136 seconds for difficult tasks (100% success). The authors also provide a baseline embodied agent using Gemini 2.5 Pro with a ReAct framework adapted for retail tasks, which completes easy tasks in 420-780 seconds with success rates of 33.33% to 68.63%, demonstrating substantial performance gaps (human agents up to 16 times faster than AI agents).

Conclusion

Sari Sandbox addresses an under-explored gap in embodied agent research by providing the first retail-specific simulation environment with high fidelity, diverse product sets, and human benchmarks. The significant performance disparity between humans and embodied agents on easy tasks indicates challenges in visual language model reasoning, decision-making, and computational efficiency for embodied tasks. Future work should optimize environment performance to stable 60 FPS, expand the human dataset with additional tasks and participants, improve embodied agent evaluation across all difficulty levels, and develop more sophisticated agent architectures with enhanced navigation and manipulation capabilities through better context engineering for vision language models.

Related Work

Embodied retail store simulators

Desktop Indoor Navigation and Simulation Environments — Matterport3D-Simulator is a visual navigation dataset built on Matterport3D enabling household navigation research; Room-to-Room benchmark provides household navigation tasks using Matterport3D; AI2-Thor is an interactive 3D environment enabling visual AI research and household task benchmarking; ION addresses instance-level object navigation with 600 household scenes; ALFRED benchmark covers everyday household tasks in AI2-Thor environments; HumanoidBench provides humanoid locomotion and manipulation tasks in MuJoCo.

General-Purpose Embodied Agent Simulators — Habitat 3.0 (Meta) is a widely-used simulator for visual exploration and diverse embodied tasks; iGibson 1.0 and iGibson 2.0 enable interactive tasks in large realistic scenes; Isaac Sim (NVIDIA) powered by Omniverse provides physics-accurate simulation; ThreeDWorld is a multi-modal physical simulation platform. A survey by Duan et al. evaluates embodied agent simulators using features including environment type, object complexity, physics fidelity, and interactivity. A survey by Wong et al. traces robotic navigation and manipulation progress from basic navigation to complex interactions in non-retail settings.

Retail and Digital Twin Applications — Paolanti et al. developed RGB-D deep learning systems for analyzing shopper movement, shelf interactions, and re-identification in real retail stores; NVIDIA Omniverse is used by retailers like Kroger and Lowe's for digital twin construction and employee training; the Future Convenience Store Challenge at the World Robot Summit proposes retail-specific tasks including item acquisition, placement, and restocking.

Embodied agents in virtual simulation

Language Grounding and Instruction Following — Huang et al. explore visual language maps for robot navigation, addressing the gap between language model semantics and spatial precision; LM-Nav targets language-guided navigation using off-the-shelf models for physical agents; ReAct framework provides the core loop (thought, action, observation, refinement) suitable for embodied tasks; StateAct extends ReAct for household environments like ALFWorld; ALFWorld aligns text and embodied environments for interactive learning.

LLM and VLM-Powered Agents — Recent advances in LLM-powered embodied agents demonstrate effectiveness in open-ended sandbox environments; NVIDIA's VOYAGER demonstrates open-ended embodied agent capabilities with large language models; Embodied Agent Interface benchmarks LLMs for embodied decision-making. The Massive Multi-discipline Multimodal Understanding and Reasoning (MMMU) benchmark provides evaluation criteria for multimodal LLMs like Gemini 2.5 Pro; Gemini family models provide state-of-the-art multimodal reasoning.

Memory Architectures for Embodied Agents — CoALA proposes cognitive architectures modeling procedural, working, semantic, and episodic memory; memory writing operations manage and utilize agent memory through summaries and recollections; a survey on memory mechanisms for large language model-based agents catalogs approaches to stateful reasoning; MemoryBank enhances LLMs with long-term memory techniques; RetLLM provides read-write memory mechanisms for language models.

Vision and Perception Tools — PaddleOCR provides robust multilingual optical character recognition for text extraction; Depth Anything V2 enables monocular depth estimation for spatial understanding.

Design Philosophy — The environment adopts evaluation criteria from a survey on embodied agents, explicitly addressing the under-explored domain of retail scenarios by considering environment type, object complexity, physics fidelity, and interactivity. The authors frame three foundational research tasks for embodied agent adaptation: visual exploration (gathering environmental data through motion and perception), visual navigation (achieving goals through embodied agent navigation), and embodied question answering (navigating and answering questions).
