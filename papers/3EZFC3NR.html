τ-bench: A Benchmark for Tool-Agent-User Interaction in Real-World Domains

Contribution

τ-bench measures an agent's ability to interact consistently with simulated human users and programmatic APIs while following domain-specific policies. The benchmark is constructed in a modular framework combining realistic databases, domain-specific API tools, policy documents, and diverse user scenarios with ground truth annotations. The authors propose a novel metric (pass^k) to evaluate agent reliability and consistency over multiple trials, distinct from pass@k (which measures discovery). Experiments on two domains (τ-retail and τ-airline) reveal that even state-of-the-art function-calling agents like gpt-4o succeed on less than 50% of tasks and show poor consistency at scale.

Research Question

How well can language agents interact with both humans and programmatic APIs over long horizons while accurately adhering to complex domain-specific policies, and how consistently do they maintain reliable behavior across multiple interactions and variations in conversation flow?

Task

τ-bench defines two domains for evaluation. τ-retail focuses on customer service tasks where agents help simulated users cancel or modify pending orders, return or exchange delivered orders, modify addresses, or provide information. Tasks involve reasoning over complex product inventories and diverse user preferences. τ-airline extends the complexity with more intricate policies, where agents must help users book, modify, or cancel flight reservations or process refunds. The airline domain includes realistic flight networks across 20 US cities with constraints on payment-method combinations, baggage allowances that vary by membership tier and cabin class, and multi-hop reasoning puzzles for constraint satisfaction.

Data

The benchmark is constructed in three stages: (1) manual design of database schemas, APIs, and policies; (2) LM-assisted generation of data entries using gpt-4 with manual refinement; (3) manual task annotation and verification. τ-retail contains 500 users, 50 products, and 1,000 orders with 115 task instances. τ-airline contains 500 users, 300 flights, and 2,000 reservations with 50 task instances. Each task specifies a user instruction (hidden from the agent) and ground truth annotations of database write actions. The user simulator is powered by gpt-4-0613 and generates natural utterances by sampling from the LM conditioned on the scenario and conversation history.

Metrics

The benchmark uses a reward r = r_action × r_output in {0,1}. r_action checks whether the final database state matches the annotated ground truth outcome, and r_output verifies that agent responses convey all necessary information to the user. The pass^k metric measures the probability that all k independent trials succeed, capturing agent consistency and robustness—distinct from pass@k which measures at least one success. By default, pass^1 (equivalent to pass@1) reports average task success. The benchmark also reports qualitative failure analysis categorizing errors into: wrong arguments (complex database reasoning failures), wrong information (omitted or miscalculated user-required data), incorrect decision-making (domain understanding and policy adherence), and partial resolution of compound requests.

Baselines

Experiments test state-of-the-art proprietary and open models: GPT-4o, GPT-4-turbo, GPT-4-32k, GPT-3.5-turbo, Claude-3-opus, Claude-3-sonnet, Claude-3-haiku, Gemini-1.5-pro, Gemini-1.5-flash, Mistral-large, Mixtral-8x22b, and Llama-3-70b. Methods evaluated include function calling (natively supported by most models) and text-formatted ReAct with and without reasoning traces. Function calling consistently outperforms text-formatted methods. Results show gpt-4o achieves 61.2% pass^1 on τ-retail and 35.2% on τ-airline; with increasing k, pass^k drops dramatically to less than 25% for pass^8. Claude-3-opus achieves 44.2% and 34.7% respectively. Ablation studies removing domain policies reveal that τ-airline performance drops more sharply (−22.4% for gpt-4o vs −4.4% for τ-retail), suggesting agents struggle more with complex ad-hoc airline policies than intuitive retail constraints.

Conclusion

τ-bench reveals that even state-of-the-art language agents lack sufficient consistency and rule-following ability for reliable real-world deployment. The benchmark enables systematic evaluation of agent improvements in long-horizon human-in-the-loop interaction, complex database reasoning, domain policy understanding, and handling of compound user requests. The modular construction facilitates extension to additional domains and serves as a foundation for developing more robust agent architectures.

Related Work

Agent and Tool-Use Benchmarks

Several benchmarks for language agents and tool-use capabilities have emerged, such as the Berkeley Function Calling Leaderboard, ToolBench, and MetaTool, which test function-calling accuracy across programming languages. ToolEmu uses language models to emulate tool execution and expose safety risks when agents fail to use tools correctly. However, these benchmarks feature single-step user interaction where humans provide all required information upfront, without multi-turn dialogue. τ-bench extends beyond these by requiring agents to gather information through interaction with simulated humans over multiple conversational turns.

Task-Oriented Dialogue Systems

Task-oriented dialogue has long been a challenge for NLP, with benchmarks ranging from static offline datasets to rule-based or symbolically-specified user simulators and crowdsourced human interactions. Recent work explores using language models as response raters to train dialogue systems and evaluates their capability for user simulation. τ-bench advances this tradition by leveraging powerful LM text generation to simulate realistic user utterances and long-context conversations from textual scenario descriptions, and crucially, uses this simulation to benchmark agent reliability rather than just demonstrate simulation fidelity.

User Simulation with Language Models

Recent efforts use language models to simulate human characters in text adventure games, multi-agent societies, collaborative tasks, and human-in-the-loop interactions for shopping and web search. These works showcase the ability of LMs to enable realistic simulations. τ-bench is novel in using such realistic user simulation to assess the reliability and robustness of AI agents for systems handling millions of real-world interactions with humans, rather than focusing solely on simulation capabilities.

Related-Work in Agent Evaluation Methodology

The paper notes that existing benchmarks do not test agents on interaction with human users or adherence to domain-specific rules, both vital for real-world deployment. τ-bench closes this gap by formulating each task as a partially observable Markov decision process (POMDP) with state space combining database and user states, and by employing an efficient evaluation process comparing database state at the episode end to annotated goals. This state-based evaluation is objective while allowing stochasticity in conversation flow.
